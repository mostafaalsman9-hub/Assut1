# علوم الرياضة أسيوط — Mobile Frontend

هذه نسخة Frontend مهيأة للرفع من الهاتف بدون مجلدات Frontend:
- index.html يحتوي HTML + CSS + JavaScript.
- icon.png وmanifest.json وsw.js موجودة في الجذر.
- لا يوجد مجلد رئيسي داخل ملف ZIP.

## Firebase
المشروع مضبوط على Firebase `drali-f6b14`.

**مهم:** GitHub Pages يشغّل الواجهة فقط. تسجيل الدخول والبيانات والوظائف الحساسة تعتمد على خدمات Firebase التي يجب أن تكون منشورة ومضبوطة في مشروعك: Authentication, Realtime Database, Cloud Functions, Storage, Rules.

لا تعتبر هذه النسخة اختبارًا حيًا للـBackend؛ الاختبار الحي يحتاج نشر خدمات Firebase ثم تجربة حسابات حقيقية.
