# منصة حضور علوم الرياضة — النسخة المحدثة

## ما تم تحديثه

- إضافة وتعديل درجات المواد للمالك فقط. الأدمن يقرأ الدرجات المسجلة دون صلاحية الإضافة أو التعديل.
- ربط الطلاب بالمدرسة أو المجموعة للمالك فقط.
- إخفاء أدوات اختيار/إسناد الطلاب من واجهة الأدمن.
- إضافة قسم «عن المنصة — خبرات المالك» يظهر للمالك فقط ويُحفظ في `ownerExperience`.
- إضافة manifest و Service Worker وزر «تثبيت التطبيق».

## التشغيل

افتح `index.html` عبر استضافة HTTPS أو عبر خادم محلي. خصائص Firebase وService Worker لا تعمل بالكامل عند فتح الملف مباشرة بصيغة `file://`.

## قواعد Firebase

انشر محتوى `firebase-database-rules.json` كاملاً في:

`Firebase Console → Realtime Database → Rules`

لا تعتبر إخفاء الأزرار حماية كافية؛ القواعد هي التي تمنع الكتابة فعلياً.
